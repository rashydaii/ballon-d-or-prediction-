# Ballon d'Or Winner Prediction using Machine Learning

## Project Overview

This project compares two classification models for predicting Ballon d'Or winners.

Models Used

- Artificial Neural Network (ANN)
- Random Forest Classifier

## Dataset

ballondor_performance_vs_pr.csv

## Technologies

- Python
- TensorFlow
- Scikit-learn
- Pandas
- Matplotlib
- Seaborn

## Performance Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- AUC-ROC
- Confusion Matrix

## Run

```bash
pip install -r requirements.txt
python main.py
```

## Results

The project compares ANN and Random Forest using classification metrics and ROC curves.
